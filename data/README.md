# Data

The raw promotion experiment is not committed to this repository.

Run:

```bash
python -m pricesense.data
```

This downloads the public Starbucks/Udacity promotion experiment copy used by
this project into `data/training.csv`.

The dataset contains randomized promotion/control assignment, a binary purchase
outcome and seven anonymized customer features (`V1`–`V7`). The experiment is
commonly used to study incremental response and promotion targeting.

The repository's MIT license applies to the project code, not to third-party
data. Refer to the source repository and original assignment for data terms and
attribution.
